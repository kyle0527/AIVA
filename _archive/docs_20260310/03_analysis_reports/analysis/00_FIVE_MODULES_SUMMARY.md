## 🎯 優先級改進建議

### 🔴 P0 (Critical) - 必須修復

#### 1. 重寫 Scan 模組漏洞檢測邏輯 (4-6 週)

**當前狀態**: ❌ 假實現，完全不可用

**需要修復**:
```python
# ❌ 錯誤示例 (當前)
async def _check_sql_injection(self, target_url: str):
    await asyncio.sleep(0.1)
    if "'" in payload:
        return [vulnerability]

# ✅ 正確實現 (需要改為)
async def _check_sql_injection(self, target_url: str):
    async with self.session.get(f"{target_url}?id={payload}") as response:
        body = await response.text()
        if self._detect_sql_error(body):
            return [vulnerability]
```

**工作量**: 4-6 週
**優先級**: **Critical**
**影響**: Scan 模組從 30% → 70% 可用

---

#### 2. 編譯多語言引擎 (1-2 週)

**當前狀態**: ❌ Rust/Go/TypeScript 引擎不可用

**需要執行**:
```bash
# Rust 引擎
cd services/scan/engines/rust_engine
cargo build --release

# Go 引擎
cd services/scan/engines/go_engine
go build -o scanner

# TypeScript 引擎
cd services/scan/engines/typescript_engine
npm install && npm run build
```

**工作量**: 1-2 週
**優先級**: **Critical**
