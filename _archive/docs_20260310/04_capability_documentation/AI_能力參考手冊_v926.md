### 如何選擇合適的 Flow

1. **根據功能需求**: 查看「按功能查詢」表格

3. **根據複雜度**: 簡單任務選2步，標準任務選3-4步，複雜整合選5步

所有 926 個 Flow 都使用統一格式：

```bash
python -m aiva_core.internal_exploration.aiva_cli_implementation --flow <ID>
```

其中 `<ID>` 的範圍是 **1 到 926**

在不確定 Flow 功能時，使用預覽模式：

```bash
python -m aiva_core.internal_exploration.aiva_cli_implementation --flow <ID> --dry-run
```

```

```
