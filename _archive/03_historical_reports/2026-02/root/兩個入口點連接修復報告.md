## 🎯 修復目標
根據之前的架構分析，修復 AIVA 系統中兩個入口點（main.py Port 9000 和 app.py Port 8000）之間的連接斷點，並確保所有組件正確整合。

## ✅ 完成的修復項目

### Phase 1: 高優先級連接（已完成）

#### 1.1 連接 ai_menu.py → app.py HTTP API ✅

**修改檔案:** `services/core/aiva_core/core_capabilities/dialog/ai_menu.py`

**修改內容:**
- ✅ 添加 `httpx` 導入（遵循 aiva_common 規範的異步 HTTP 客戶端）

  - 降級方案：如果 httpx 不可用，使用原有的 AI 助理
- ✅ 新增 `_execute_via_http_api()` 方法：處理 HTTP 請求和響應
- ✅ 新增 `_execute_via_ai_assistant()` 方法：降級方案
- ✅ 添加詳細的錯誤處理和用戶提示

**效果:**
- 用戶在 CLI 選單中選擇「一鍵攻擊」會直接調用 app.py 的 HTTP API
- 統一了 HTTP 和 CLI 兩種方式的掃描流程
- 提供清晰的掃描狀態和結果顯示
