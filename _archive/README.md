This directory contains archived files, completed projects, and deprecated components from the AIVA project.

## Quick Reference

- Use timestamp prefixes for all archived items
- Maintain clear directory separation by type
- Document reasons for archiving in commit messages
- Review and clean archives periodically

## Archive Policy

1. **Completed Projects**: Move to 01_completed_projects with completion date
2. **Deprecated Code**: Move to 02_deprecated_code with deprecation reason
3. **Historical Reports**: Preserve in 03_historical_reports
4. **Completed Scripts**: Archive working scripts in 04_scripts_completed
5. **Backups**: Keep important backups in 05_backups
