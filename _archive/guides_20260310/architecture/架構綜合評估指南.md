## 🔄 架構演進路徑

### 階段 1：複雜三層架構（已廢棄）

```
❌ Orchestrator (AI 決策層)
      ↓
❌ Coordinator (協調層)      ← 冗餘！
      ↓
❌ Dispatcher (消息路由層)    ← 冗餘！
      ↓
   模組執行
```

**問題**：
- Coordinator/Dispatcher 從未被實際使用
- AI 已通過 subprocess 直接調用 CLI
- 維護成本高，無實際價值

### 階段 2：雙 CLI 架構（當前）

```
✅ AI (EnhancedDecisionAgent)
      ↓
   決策 + 規劃
      ↓
   ┌──────┴──────┐
   ↓             ↓
FlowExecutor  Dispatcher
(Python)      (Rust/Go/TS)
   ↓             ↓
importlib    subprocess
```

**優點**：
- 移除冗餘層
- Python 模組零開銷（importlib）
- 跨語言工具用 subprocess

### 階段 3：AI 排序器方案（提案）

```
🆕 EnhancedDecisionAgent
    ├─ 決策能力
    ├─ 排序能力 ← NEW！
    ├─ 並發控制 ← NEW！
    └─ 執行優化 ← NEW！
         ↓
   直接執行（無中間層）
         ↓
   ┌──────┴──────┐
   ↓             ↓
FlowExecutor  Dispatcher
```

**優點**：
- 排序邏輯是 AI 決策的一部分
- 簡化輸入（用戶只提供目標 + 意圖）
- AI 自動判斷優先級、順序、並發數

```python
    # ========== 新增方法 ==========
    
    async def execute_mission(
        self, 
        target: str, 
        intent: str
    ) -> dict:
        """執行任務（簡化輸入）
        
        Args:
            target: 目標 URL/IP
            intent: 意圖（find_vulnerabilities, compliance_check, etc.）
        
        Returns:
            整合結果
        """
        # 1. AI 決策：選擇工具
        tools = await self._select_tools(target, intent)
        
        # 2. AI 排序：優先級計算
        sorted_tools = self._intelligent_sort(tools)
        
        # 3. 執行：並發控制
        results = await self._execute_with_concurrency(sorted_tools)
        
        # 4. 整合結果
        return self._integrate_results(results)
    
    def _intelligent_sort(self, tasks: list[dict]) -> list[dict]:
        """智能排序（AI 排序能力）
        
        混合策略：70% 規則 + 30% AI（初期）
        """
        # 基礎規則排序
        priority_map = {'recon': 1, 'scan': 2, 'exploit': 3}
        tasks_sorted = sorted(
            tasks,
            key=lambda t: priority_map.get(t.get('type'), 999)
        )
        
        # AI 微調（如果有足夠數據）
        if self.telemetry_confidence > 0.7:
            tasks_sorted = self._neural_priority_sort(tasks_sorted)
        
        return tasks_sorted
    
    async def _execute_with_concurrency(
        self, 
        tasks: list[dict]
    ) -> list[dict]:
        """並發執行（自動控制並發數）"""
        semaphore = asyncio.Semaphore(self.max_concurrent)
        
        async def execute_single(task):
            async with semaphore:
                return await self._execute_tool(task)
        
        results = await asyncio.gather(*[execute_single(t) for t in tasks])
        return results
```
