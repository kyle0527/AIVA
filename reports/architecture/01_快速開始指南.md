## 整合模組概述

### 模組定位

AIVA 整合模組是系統的**數據中樞**，負責：
- 📦 統一管理所有模組的資料儲存
- 🔄 協調跨模組的資料流轉
- 📊 提供統一的資料查詢接口
- 💾 自動化資料備份與維護

### 核心價值

| 價值點 | 說明 | 影響 |
|-------|------|------|
| **統一管理** | 單一入口點管理所有資料 | 降低複雜度 |
| **規範遵循** | 100% 使用 aiva_common 標準 | 保證一致性 |
| **多資料源** | 支援 3 種資料庫 | 提高靈活性 |
| **自動化** | 自動持久化、備份、清理 | 減少維護成本 |

### 架構概覽

```
┌─────────────────────────────────────────────────────────┐
│          各模組 (Core / Features / Scan / Reporting)     │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
         ┌─────────────────────────────┐
         │   UnifiedDataManager        │
         │   (統一資料管理器)           │
         └──────────┬──────────────────┘
                    │
        ┌───────────┼───────────┐
        │           │           │
        ▼           ▼           ▼
┌──────────┐ ┌──────────┐ ┌──────────┐
│PostgreSQL│ │  SQLite  │ │ NetworkX │
│(漏洞發現)│ │(經驗記錄)│ │(攻擊路徑)│
└──────────┘ └──────────┘ └──────────┘
```

## 安裝與配置

### 環境要求

- Python 3.11+
- PostgreSQL 15+ (含 pgvector)
- SQLite 3.35+
- 磁碟空間: 至少 10GB

### 安裝步驟

```bash
# 1. 安裝依賴
cd services/integration
pip install -r requirements.txt

# 2. 配置環境變數 (可選，已有預設值)
# PostgreSQL: 預設 postgresql://postgres:postgres@localhost:5432/aiva_db
# 如需修改，編輯 config.py 中的 DATABASE_URL

# 3. 初始化資料庫
python -m alembic upgrade head

# 4. 驗證安裝
python -c "
from services.integration.aiva_integration.unified_data_manager import get_unified_data_manager
manager = get_unified_data_manager()
print('✅ 整合模組安裝成功')
"
```

### 配置說明

**自動配置** (`config.py` 已預設)：

```python
# 資料庫連接 (預設值)
DATABASE_URL = "postgresql://postgres:postgres@localhost:5432/aiva_db"
EXPERIENCE_DB_URL = "sqlite:///data/integration/experiences/experience.db"

# 文件路徑 (自動創建)
ATTACK_GRAPH_FILE = "data/integration/attack_paths/attack_graph.pkl"
TRAINING_DATASET_DIR = "data/integration/training_datasets"
BACKUP_DIR = "data/integration/backups"

# 備份設定 (預設值)
BACKUP_RETENTION_DAYS = {
    "attack_graph": 7,      # 攻擊路徑圖保留 7 天
    "experience_db": 30,    # 經驗資料庫保留 30 天
    "training_dataset": 90, # 訓練資料集保留 90 天
}
```

**自定義配置** (如需修改)：

編輯 `services/integration/aiva_integration/config.py`：

```python
# 修改 PostgreSQL 連接
DATABASE_URL = "postgresql://user:pass@host:5432/db_name"
```

## 快速開始

### 基本初始化

```python
from services.integration.aiva_integration.unified_data_manager import (
    get_unified_data_manager,
)

# 獲取管理器實例（單例模式）
manager = get_unified_data_manager()

# 現在可以使用所有功能
print("✅ 整合模組已就緒")
```

### 常用操作流程

```
1. 初始化管理器
   ↓
2. 保存資料 (經驗/漏洞/資產)
   ↓
3. 查詢資料
   ↓
4. 獲取統計資訊
   ↓
5. 生成報告
```

## 基本使用範例

### 範例 1: 保存攻擊經驗 (Core 模組)

```python
from services.integration.aiva_integration.unified_data_manager import (
    get_unified_data_manager,
)

manager = get_unified_data_manager()

# 保存攻擊經驗
record = manager.save_attack_experience(
    plan_id="plan_001",
    attack_type="sqli",
    ast_graph={"nodes": [...], "edges": [...]},
    execution_trace={"steps": [...], "success": True},
    metrics={"completion_rate": 0.95, "overall_score": 0.92},
    feedback={"reward": 0.9},
)

print(f"✅ 經驗已保存: {record.experience_id}")
```

### 範例 2: 保存漏洞發現 (Features 模組)

```python
from services.aiva_common.schemas import FindingPayload
from services.aiva_common.enums import Severity, Confidence

manager = get_unified_data_manager()

# 創建漏洞發現
finding = FindingPayload(
    finding_id="sqli_001",
    affected_url="http://example.com/api/user?id=1",
    severity=Severity.CRITICAL,
    confidence=Confidence.HIGH,
    vulnerability_type="sql_injection",
    description="SQL Injection in user ID parameter",
)

# 保存漏洞
manager.save_finding(finding, scan_id="scan_001")
print("✅ 漏洞已保存到資料庫")
```

### 範例 3: 查詢資料

```python
# 查詢高質量經驗
experiences = manager.query_high_quality_experiences(
    attack_type="sqli",
    min_score=0.8,
    limit=50,
)

# 查詢漏洞
findings = manager.query_findings(
    severity=Severity.HIGH,
    status="active",
)

# 獲取統計資訊
stats = manager.get_unified_statistics()
print(f"總經驗數: {stats['experiences']['total_experiences']}")
print(f"嚴重漏洞: {stats['findings']['by_severity']['CRITICAL']}")
```

### 範例 4: 註冊資產 (Scan 模組)

```python
# 註冊掃描發現的資產
manager.add_asset_to_attack_graph(
    asset_id="web_app_001",
    asset_type="web_application",
    url="https://example.com",
    metadata={
        "framework": "Django",
        "version": "3.2",
        "ports": [80, 443],
    },
)

# 保存攻擊圖
manager.save_attack_graph()
print("✅ 資產已註冊")
```

## 常見使用場景

### 場景 1: AI 學習系統 (Core 模組)

```python
# 1. 查詢歷史經驗
historical_experiences = manager.query_high_quality_experiences(
    attack_type="sqli",
    min_score=0.85,
    limit=100,
)

# 2. 執行新攻擊...
# 3. 記錄新經驗
manager.save_attack_experience(...)

# 4. 導出訓練資料集
dataset_path = manager.export_training_dataset(
    attack_type="sqli",
    min_score=0.8,
    max_samples=1000,
)
```

### 場景 2: 漏洞掃描 (Features 模組)

```python
# 1. 執行漏洞測試...
# 2. 保存發現
for finding in discovered_vulnerabilities:
    manager.save_finding(finding, scan_id="scan_001")

# 3. 查詢漏洞統計
stats = manager.get_finding_statistics(scan_id="scan_001")
print(f"發現漏洞: {stats['total_findings']}")
print(f"嚴重: {stats['by_severity']['CRITICAL']}")
```

```python
# 獲取綜合統計
stats = manager.get_unified_statistics()

findings = manager.query_findings(scan_id="scan_001")

# 獲取攻擊路徑資訊
attack_graph_stats = manager.get_attack_graph_statistics()

# 構建報告...
```
