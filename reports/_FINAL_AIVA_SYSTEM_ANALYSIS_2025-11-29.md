## 🧠 AI 運作機制

### 核心決策引擎 (Enhanced Decision Agent)

#### 運作流程
1. **意圖識別**: 解析高層級用戶意圖
2. **風險評估**: 基於 RiskLevel 枚舉評估安全風險
3. **經驗驅動**: 整合歷史經驗和學習結果
4. **規則引擎**: 應用內建安全規則
5. **動態執行**: 實時調整和決策

#### 技術特點
```python
class EnhancedDecisionAgent:
    def decide(self, intent: HighLevelIntent) -> Decision:
        # 1. 風險分析
        risk = self.assess_risk(intent)
        
        # 2. 經驗查詢
        experience = self.query_experience(intent)
        
        # 3. 規則匹配
        rules = self.match_rules(intent)
        
        # 4. 決策生成
        return self.generate_decision(risk, experience, rules)
```
