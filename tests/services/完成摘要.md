## 📋 新的測試規範 (v2.0)

### 核心原則
> **`services/` 目錄僅包含生產代碼，所有測試文件統一管理於 `tests/` 目錄**

### ✅ 正確做法
```
tests/
└── services/
    ├── scan/              # 掃描模組測試
    ├── core/              # 核心模組測試
    └── features/          # 功能模組測試
```

### ❌ 禁止行為
```
services/
├── scan/
│   └── test_xxx.py        # ❌ 禁止
└── core/
    └── tests/             # ❌ 禁止
```

### 測試執行要求
1. **實際執行測試**，不僅僅創建文件
2. **測試真實組件**，避免過度使用 Mock
3. **使用絕對導入**引用生產代碼
4. **持續整合測試**，提交前執行完整測試套件

## 🚀 快速開始

### 執行測試
```bash
# 執行所有測試
pytest tests/services/ -v

# 執行特定模組
pytest tests/services/scan/ -v

# 生成覆蓋率報告
pytest tests/services/ --cov=services --cov-report=html
```

### 添加新測試
```bash
# 1. 在正確位置創建測試文件
# tests/services/your_module/test_your_feature.py

# 2. 使用絕對導入
from services.your_module import YourClass

# 3. 執行測試驗證
pytest tests/services/your_module/test_your_feature.py -v
```
