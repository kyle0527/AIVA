3. ✅ **新增閱讀指南**：幫助用戶快速找到需要的手冊

### 修正內容

**重要修正：Phase 0 架構**

| 項目 | 舊版本（錯誤） | 新版本（正確） |
|------|-------------|-------------|
| **步驟劃分** | Step 3-4 合併執行 | Step 3 規劃 → Step 4 執行 → Step 5 整合 |
| **執行方式** | 單一探查或順序執行 | 5+ 路並行探查 |
| **探查類型** | 簡單 HTTP 探測 | HTTP + 端口 + WAF + 技術棧 + 目錄 |
| **AI 決策依據** | 不完整的單一結果 | 整合後的完整情報 |

**為什麼這樣改？**

根據系統實際設計原則：
1. **黑盒測試**：完全不知道目標情況，需要多路並行探查
2. **規劃與執行分離**：步驟 N 的輸出 → 步驟 N+1 的輸入依據
3. **Rust 引擎**：負責高性能並行執行（6 倍性能提升）
