## 1. 模組概覽

AIVA 的功能模組分為**內部能力**和**外部能力**兩類：

| 類別 | 說明 | 範例 |
|------|------|------|
| 內部能力 | AI Core 內建功能 | 決策、規劃、學習 |
| 外部能力 | 獨立工具/引擎 | 掃描引擎、漏洞檢測工具 |

### 模組架構

```
services/
├── core/aiva_core/          # 內部能力 (AI Core)
│   ├── cognitive_core/      # 認知核心
│   ├── task_planning/       # 任務規劃
│   └── internal_exploration/ # 自我探索
│
├── scan/                    # 掃描引擎
│   ├── rust_engine/         # Rust 高性能引擎
│   ├── python_engine/       # Python 引擎
│   └── typescript_engine/   # TypeScript 引擎
│
└── features/                # 功能模組
    ├── function_xss/        # XSS 檢測
    ├── function_ssrf/       # SSRF 檢測
    └── function_bizlogic/   # 業務邏輯漏洞
```

### 能力管理核心模組

功能模組由以下核心檔案管理和編排：

| 檔案 | 位置 | 職責 |
|------|------|------|
| `capability_orchestrator.py` | `cognitive_core/` | 能力編排器，協調多能力組合執行 |
| `capability_registry.py` | `core_capabilities/` | 能力註冊中心，維護所有可用能力清單 |
| `capability_manager.py` | `task_planning/commander/` | 能力管理器，處理能力查詢與匹配 |
| `attack_chain.py` | `core_capabilities/attack/` | 攻擊鏈構建，組合多個攻擊步驟 |
| `exploit_orchestrator.py` | `core_capabilities/attack/` | 攻擊編排器，管理漏洞利用流程 |
| `two_phase_scan_orchestrator.py` | `core_capabilities/orchestration/` | 兩階段掃描編排，協調 Phase 0/1 |

#### 能力管理架構

```
用戶請求
    ↓
capability_registry.py     ← 查詢可用能力
    ↓
capability_manager.py      ← 能力匹配與選擇
    ↓
capability_orchestrator.py ← 能力組合編排
    ├── two_phase_scan_orchestrator.py  ← 掃描流程
    └── attack_chain.py + exploit_orchestrator.py  ← 攻擊流程
    ↓
執行結果
```

## 2. 掃描模組

### 模組概覽

AIVA 掃描模組是系統中最大的功能模組：

| 指標 | 數值 |
|------|------|
| 掃描能力數 | **286 個** |
| 佔總能力比例 | 36.6% |
| 支援語言 | Python, Rust, TypeScript, Go |

### 掃描引擎說明

| 引擎 | 語言 | 特點 | 使用場景 |
|------|------|------|---------|
| Rust Engine | Rust | 高性能、低延遲 | 大規模掃描 |
| Python Engine | Python | 靈活、易擴展 | 複雜邏輯檢測 |
| TypeScript Engine | TS | 前端分析 | DOM/XSS 分析 |

### 掃描策略

| 策略 | 時間 | 內容 | 建議場景 |
|------|------|------|---------|
| 快速策略 | 5-10 分鐘 | Phase 0 only, Top 1000 端口 | 臨時測試 |
| 標準策略 | 15-20 分鐘 | Phase 0 + Phase 1 | 日常使用 |
| 深度策略 | 30-60 分鐘 | 全端口, 完整漏洞庫 | 重要系統 |

### 使用範例

```powershell
# 進入工作目錄
cd C:\D\fold7\AIVA-git\services\core

# === 方式一：使用 Internal Executor（推薦）===

# 列出所有可用 Flow
python -m aiva_core.internal_exploration.aiva_internal_executor --list

# 執行特定 Flow（如 XSS 相關的 Flow 14）
python -m aiva_core.internal_exploration.aiva_internal_executor --flow 14

# 預覽模式（不執行）

# === 方式二：使用 External Executor（多語言）===

# 列出外部模組能力
python -m aiva_core.internal_exploration.aiva_external_executor --list

# 按語言篩選
python -m aiva_core.internal_exploration.aiva_external_executor --list --lang rust

# 執行 Python 流程
python -m aiva_core.internal_exploration.aiva_external_executor --lang python --flow 1

# === 方式三：使用批次檔（最簡單）===
# 在專案根目錄（C:\D\fold7\AIVA-git）

啟動能力選單.bat          # 啟動互動式選單
執行Flow.bat 14           # 執行指定 Flow
預覽Flow.bat 14           # 預覽 Flow（不執行）
```

reports/scan_*.html      # HTML 格式報告

## 4. RAG 智能攻擊系統

### 4.1 系統概覽

RAG 智能攻擊系統 (v4.4.1) 是 AIVA 最新的攻擊能力管理系統，直接使用 AST 分類器產出的資料進行智能攻擊決策。

| 組件 | 位置 | 功能 |
|------|------|------|
| `cli_decision_engine.py` | `cognitive_core/learning_system/` | CLI 決策引擎，525 條攻擊流程管理 |
| `flow_executor_adapter.py` | `cognitive_core/learning_system/` | 執行適配器，橋接決策與執行 |
| `attack_coordinator.py` | `task_planning/commander/` | 攻擊協調器，整合 RAG 智能攻擊 |

### 4.2 能力統計

RAG 系統支援 **525 條攻擊流程**，其中 **287 條可操作 (54.7%)**：

| 攻擊類型 | 可操作/總數 | 百分比 |
|---------|------------|--------|
| XSS | 48/97 | 49.5% |
| SQLi | 68/115 | 59.1% |
| SSRF | 28/64 | 43.8% |
| Scanner | 27/74 | 36.5% |
| PostEx | 28/49 | 57.1% |
| BizLogic | 46/53 | 86.8% |
| IDOR | 14/25 | 56.0% |
| InfoLeak | 14/20 | 70.0% |
| Python | 10/24 | 41.7% |

### 4.3 RAG 智能攻擊使用

#### 方法 1: 智能模式攻擊

```python
from services.core.aiva_core.task_planning.commander.attack_coordinator import AttackCoordinator

# 1. 創建攻擊協調器
coordinator = AttackCoordinator()

# 2. 執行 RAG 智能攻擊（自動模式）
results = coordinator.rag_smart_attack(
    target="https://testphp.vulnweb.com",
    mode="auto"  # 選擇前 3 個最佳流程
)

# 3. 執行 RAG 智能攻擊（積極模式）
results = coordinator.rag_smart_attack(
    target="https://testphp.vulnweb.com",
    mode="aggressive"  # 選擇前 5 個流程，更全面
)

# 4. 執行 RAG 智能攻擊（謹慎模式）
results = coordinator.rag_smart_attack(
    target="https://testphp.vulnweb.com",
    mode="cautious"  # 只選擇 Top 1，減少噪音
)
```

#### 方法 2: 針對性攻擊

```python
# 針對特定漏洞類型
results = coordinator.rag_targeted_attack(
    target="https://testphp.vulnweb.com",
    capability="xss",  # 只測試 XSS
    top_k=3
)

# 支援的能力類型
capabilities = ["xss", "sqli", "ssrf", "scanner", "postex", 
                "bizlogic", "idor", "infoleak", "authn", "crypto"]
```

#### 方法 3: 使用 CLI 決策引擎

```python
from services.core.aiva_core.cognitive_core.learning_system.cli_decision_engine import CLIDecisionEngine

# 1. 創建決策引擎
engine = CLIDecisionEngine()

# 2. 搜索攻擊流程
flows = engine.search_flows(capability="sqli", limit=5)

# 3. 獲取推薦流程
recommendations = engine.recommend_flows(
    target_info={"tech_stack": ["php", "mysql"]},
    top_k=3
)

# 4. 獲取模組統計
stats = engine.get_module_statistics()
print(f"總流程: {stats['total_flows']}")
print(f"可操作: {stats['operable_flows']}")
```

### 4.4 執行配置

**重要**: RAG 智能攻擊系統已移除 Dry Run 模式，直接執行真實攻擊。

```python
from services.core.aiva_core.cognitive_core.learning_system.flow_executor_adapter import (
    FlowExecutorAdapter, ExecutionConfig
)

# 創建執行配置
config = ExecutionConfig(
    timeout=300,        # 超時 300 秒
    max_retries=2,      # 最多重試 2 次
    verbose=True        # 輸出詳細日誌
)

# 創建執行適配器
adapter = FlowExecutorAdapter(config=config)

# 執行推薦的流程
results = adapter.execute_recommended_flows(
    target="https://testphp.vulnweb.com",
    recommended_flows=recommendations
)
```

## 5. 學習系統

### 學習系統概覽

學習系統位於 `cognitive_core/learning_system/`，負責：
- 📊 從執行結果學習 - 分析每次掃描/攻擊的結果
- 🧠 優化策略 - 根據歷史經驗調整測試策略
- 🎯 參數建議 - 建議最佳 CLI 參數組合

### 快速使用

```python
from cognitive_core.learning_system.analysis import StrategyAdjuster

# 1. 創建策略調整器
adjuster = StrategyAdjuster()

# 2. 從結果中學習
adjuster.learn_from_result({
    "scan_id": "scan_001",
    "module": "sqli",
    "success": True,
    "vulnerability": {"severity": "HIGH", "confidence": "CONFIRMED"},
    "waf_status": "bypassed",
    "parameters_used": {"mode": "stealth", "delay": 500}
})

# 3. 獲取統計
stats = adjuster.get_reward_statistics()
print(f"總學習次數: {stats['total_episodes']}")
print(f"平均獎勵: {stats['avg_reward']:.2f}")
```

### 獎勵配置

| 結果類型 | 獎勵值 | 說明 |
|---------|-------|------|
| `VULN_CONFIRMED` | +10.0 | 確認漏洞 |
| `WAF_BYPASS` | +15.0 | 成功繞過 WAF |
| `EXECUTION_FAILURE` | -5.0 | 執行失敗 |

### 參數建議

```python
# 獲取建議參數
suggested = adjuster.suggest_parameters(
    module="xss",
    context={"waf_detected": True}
)
# 輸出: {"mode": "stealth", "delay": 500, "payload_type": "php_specific"}
```
