## 1. 模組概覽

AIVA 的功能模組分為**內部能力**和**外部能力**兩類：

| 類別 | 說明 | 範例 |
|------|------|------|
| 內部能力 | AI Core 內建功能 | 決策、規劃、學習 |
| 外部能力 | 獨立工具/引擎 | 掃描引擎、漏洞檢測工具 |

### 模組架構

```
services/
├── core/aiva_core/          # 內部能力 (AI Core)
│   ├── cognitive_core/      # 認知核心
│   ├── task_planning/       # 任務規劃
│   └── internal_exploration/ # 自我探索
│
├── scan/                    # 掃描引擎
│   ├── rust_engine/         # Rust 高性能引擎
│   ├── python_engine/       # Python 引擎
│   └── typescript_engine/   # TypeScript 引擎
│
└── features/                # 功能模組
    ├── function_xss/        # XSS 檢測
    ├── function_ssrf/       # SSRF 檢測
    └── function_bizlogic/   # 業務邏輯漏洞
```

## 2. 掃描模組

### 模組概覽

AIVA 掃描模組是系統中最大的功能模組：

| 指標 | 數值 |
|------|------|
| 掃描能力數 | **286 個** |
| 佔總能力比例 | 36.6% |
| 支援語言 | Python, Rust, TypeScript, Go |

### 掃描引擎說明

| 引擎 | 語言 | 特點 | 使用場景 |
|------|------|------|---------|
| Rust Engine | Rust | 高性能、低延遲 | 大規模掃描 |
| Python Engine | Python | 靈活、易擴展 | 複雜邏輯檢測 |
| TypeScript Engine | TS | 前端分析 | DOM/XSS 分析 |

### 掃描策略

| 策略 | 時間 | 內容 | 建議場景 |
|------|------|------|---------|
| 快速策略 | 5-10 分鐘 | Phase 0 only, Top 1000 端口 | 臨時測試 |
| 標準策略 | 15-20 分鐘 | Phase 0 + Phase 1 | 日常使用 |
| 深度策略 | 30-60 分鐘 | 全端口, 完整漏洞庫 | 重要系統 |

### 使用範例

```batch
# 快速掃描
python aiva_cli.py --attack "快速掃描 http://localhost:3000"

# 深度掃描
python aiva_cli.py --attack "深度掃描 http://localhost:3000"

# 完整測試（Phase 0 + Phase 1）
python aiva_cli.py --attack "完整測試 http://localhost:3000"

# 指定引擎
python -m services.core.aiva_core.core_capabilities.cli.aiva_cli flow0 ^
  --target https://example.com ^
  --param engine=rust
```

### 掃描結果位置

```
logs/scan_*.log          # 掃描日誌
reports/scan_*.json      # JSON 格式報告
reports/scan_*.html      # HTML 格式報告
data/scan_results/       # 原始數據
```

## 4. 學習系統

### 學習系統概覽

學習系統位於 `cognitive_core/learning_system/`，負責：
- 📊 從執行結果學習 - 分析每次掃描/攻擊的結果
- 🧠 優化策略 - 根據歷史經驗調整測試策略
- 🎯 參數建議 - 建議最佳 CLI 參數組合

### 快速使用

```python
from cognitive_core.learning_system.analysis import StrategyAdjuster

# 1. 創建策略調整器
adjuster = StrategyAdjuster()

# 2. 從結果中學習
adjuster.learn_from_result({
    "scan_id": "scan_001",
    "module": "sqli",
    "success": True,
    "vulnerability": {"severity": "HIGH", "confidence": "CONFIRMED"},
    "waf_status": "bypassed",
    "parameters_used": {"mode": "stealth", "delay": 500}
})

# 3. 獲取統計
stats = adjuster.get_reward_statistics()
print(f"總學習次數: {stats['total_episodes']}")
print(f"平均獎勵: {stats['avg_reward']:.2f}")
```

### 獎勵配置

| 結果類型 | 獎勵值 | 說明 |
|---------|-------|------|
| `VULN_CONFIRMED` | +10.0 | 確認漏洞 |
| `WAF_BYPASS` | +15.0 | 成功繞過 WAF |
| `EXECUTION_FAILURE` | -5.0 | 執行失敗 |

### 參數建議

```python
# 獲取建議參數
suggested = adjuster.suggest_parameters(
    module="xss",
    context={"waf_detected": True}
)
# 輸出: {"mode": "stealth", "delay": 500, "payload_type": "php_specific"}
```

## 5. 模組選單操作

### 互動式選單

```
===== AIVA 能力瀏覽器 =====
[1] 認知核心模組        | 45 種能力
[2] 內探模組            | 32 種能力
[3] 任務規劃模組        | 28 種能力
[4] 核心能力模組        | 15 種能力
[5] 服務骨幹模組        | 20 種能力
[0] 離開

> 請選擇模組: 1

===== 認知核心模組 - 能力列表 =====
[1] process_command → execute_task
[2] analyze_context → plan_strategy
...

> 輸入 "1" 執行
> 輸入 "v 1" 預覽
```

### 快捷操作

| 指令 | 功能 |
|------|------|
| `1` | 執行第 1 個能力 |
| `v 1` | 預覽（dry-run）第 1 個能力 |
| `b` | 返回上一層 |
| `0` | 離開選單 |
