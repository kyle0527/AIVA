### 內循環 (Inner Loop) - Know Thyself

讓 AI 知道自己有哪些能力。

```
探索系統 → 分析能力 → 同步到 RAG → 測試自我認知
   (5s)      (10s)       (5s)         (5s)
```

**預期結果**:
- 掃描 4 個模組
- 發現 800 個能力
- 注入 782 個 RAG 文檔
- 數據庫大小: ~10 MB

#### 執行自我認知更新

```powershell
# 確保在專案根目錄
cd C:\D\fold7\AIVA-git

# 執行內閉環
python scripts\core\update_self_awareness.py
```

#### 測試自我認知查詢

```powershell
python -c "
import asyncio
from scripts.core.update_self_awareness import test_self_awareness_query
asyncio.run(test_self_awareness_query())
"
```

測試查詢範例：
- 「我有哪些攻擊能力?」
- 「SQLi 攻擊的健康狀態如何?」
- 「推薦優先優化哪個模組?」

### 外循環 (Outer Loop) - Learn from Battle

從實戰中學習，優化攻擊策略。

**學習內容**:
- 成功經驗：哪些攻擊有效
- 失敗教訓：哪些策略無效
- 偏差分析：計劃 vs 實際執行
- 權重更新：調整決策模型

**執行方式**:
```python
# 執行攻擊任務（自動觸發外部閉環）
from services.core.aiva_core import AIVACore

aiva = AIVACore()
result = await aiva.execute_attack({
    "target": "http://target.com",
    "attack_plan": attack_plan,
    "collect_experience": True  # 啟用經驗收集
})
```

## 2. 自訂模組開發

### 添加新的 Flow

1. **在目標模組添加新類別**：
```python
# services/features/your_module/your_feature.py
class YourFeature:
    def execute(self, params: dict) -> dict:
        # 實作邏輯
        return {"status": "success", "data": ...}
```

2. **重新執行分析管道**：
```batch
python aiva_exploration_pipeline.py --target .
```

3. **新 Flow 會自動出現在選單中**

### 自訂分類規則

編輯 `aiva_flow_classifier.py`：

```python
# 添加新模組
MODULES = {
    "your_module": "您的模組名稱",
    # ...
}

# 添加描述
SCRIPT_DESCRIPTIONS = {
    "your_script.py": "腳本功能說明",
}
```

## 3. CLI 擴展

### 添加新命令

CLI 入口點：
```
services/core/aiva_core/core_capabilities/cli/aiva_cli.py
```

使用 Typer 框架添加命令：

```python
@app.command()
def your_command(
    target: str = typer.Option(..., "--target", "-t"),
    param: str = typer.Option(None, "--param", "-p"),
):
    """您的命令說明"""
    # 實作邏輯
```

### 自訂批次檔

創建新的 `.bat` 檔案：

```batch
@echo off
chcp 65001 >nul 2>&1
set PYTHONPATH=C:\D\fold7\AIVA-git;C:\D\fold7\AIVA-git\services
set PYTHONIOENCODING=utf-8

python -m services.core.aiva_core.core_capabilities.cli.aiva_cli 您的命令 %*

pause
```

## 4. 分析管道操作

### 完整管道執行

```batch
cd services/core/aiva_core/internal_exploration
python aiva_exploration_pipeline.py --target core
```

### 三階段說明

| 階段 | 工具 | 輸出 |
|------|------|------|
| Stage 1 | `aiva_flow_analyzer.py` | flows.json |
| Stage 2 | `aiva_flow_classifier.py` | classification_data.json |
| Stage 3 | `aiva_cli_implementation.py` | 互動執行 |

### 版本控制

```
analysis_history/
├── v1/
├── v2/
└── latest -> v2  # 符號連結
```

## 5. 進階配置

### 環境變數

| 變數 | 說明 | 預設值 |
|------|------|--------|
| `PYTHONPATH` | Python 模組路徑 | 專案根目錄 |
| `PYTHONIOENCODING` | 編碼設定 | utf-8 |
| `AIVA_ENV` | 運行環境 | production |
| `AIVA_LOG_LEVEL` | 日誌級別 | INFO |

### 配置檔案

```
config/
├── settings.yaml    # 主設定
├── logging.yaml     # 日誌設定
└── features.yaml    # 功能開關
```
