### 1.1 內循環 (Inner Loop) - Know Thyself

讓 AI 知道自己有哪些能力。內循環使用 `internal_exploration` 模組進行自我探索。

```
AST 分析 → 流程分類 → 能力列表 → 執行測試
  (10s)     (5s)       (即時)      (依流程)
```

**預期結果**:
- 內部模組：171 條流程（AI Core）
- 外部模組：525 條流程（Features + Scan）
- 支援 4 種語言：Python, Go, Rust, TypeScript

#### 三階段管道執行

```powershell
# 進入工作目錄
cd C:\D\fold7\AIVA-git\services\core

# === Stage 1: AST 分析（Python 模組）===
python -m aiva_core.internal_exploration.python_tools.aiva_flow_analyzer --target ../.. --output ./analysis

# === Stage 2: 流程分類 ===
# 內部模組分類（AI Core）
python -m aiva_core.internal_exploration.aiva_internal_classifier

# 外部模組分類（Features + Scan）
python -m aiva_core.internal_exploration.aiva_external_classifier

# === Stage 3: 能力執行 ===
# 列出所有可用流程
python -m aiva_core.internal_exploration.aiva_internal_executor --list

# 執行特定流程
python -m aiva_core.internal_exploration.aiva_internal_executor --flow 8

# 預覽模式（不實際執行）

# 啟動互動式選單
python -m aiva_core.internal_exploration.aiva_internal_executor --menu
```

#### 快速執行（使用批次檔）


### 1.2 外循環 (Outer Loop) - Learn from Battle

從實戰中學習，優化攻擊策略。外循環使用 `aiva_external_executor` 執行實際的攻擊能力。

**學習內容**:
- 成功經驗：哪些攻擊有效
- 失敗教訓：哪些策略無效
- 偏差分析：計劃 vs 實際執行
- 權重更新：調整決策模型

#### 外部執行器使用

```powershell
# 進入工作目錄
cd C:\D\fold7\AIVA-git\services\core

# 列出所有外部能力
python -m aiva_core.internal_exploration.aiva_external_executor --list

# 列出特定語言能力
python -m aiva_core.internal_exploration.aiva_external_executor --list --lang rust
python -m aiva_core.internal_exploration.aiva_external_executor --list --lang go
python -m aiva_core.internal_exploration.aiva_external_executor --list --lang python

# 執行 Python 流程
python -m aiva_core.internal_exploration.aiva_external_executor --lang python --flow 1

# 執行 Rust 函數（Cookie 分析）
python -m aiva_core.internal_exploration.aiva_external_executor --lang rust --func analyze_cookies `
  --cookies-json '["sessionid=abc"]' --url 'https://example.com'

# Dry Run 模式（預覽不執行）
python -m aiva_core.internal_exploration.aiva_external_executor --lang rust --func analyze_cookies `

# 啟動互動式選單
python -m aiva_core.internal_exploration.aiva_external_executor --menu
```

#### 支援的語言和能力

| 語言 | 模組範例 | 能力數量 | 執行方式 |
|------|---------|---------|---------|
| Python | XSS, SQLi, SSRF | ~500+ | 直接導入 |
| Rust | Cookie 分析, 加密 | ~10 | subprocess |
| Go | 認證模組 | ~5 | subprocess |
| TypeScript | 前端分析 | ~3 | npx ts-node |

```yaml
on:
  push:
    branches: [ main ]

    - cron: '0 0 * * *'  # 每日執行

jobs:
  scan:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.13'
      
      - name: Install Dependencies
        run: |
          pip install -r services/core/requirements.txt
      
      - name: Run Security Scan
        run: |
          python services/core/aiva_core/core_capabilities/cli/aiva_cli.py scan \
            --target ${{ secrets.TARGET_URL }} \
            --output scan_results.json
      
      - name: Upload Results
        uses: actions/upload-artifact@v3
        with:
          name: scan-results
          path: scan_results.json
```
