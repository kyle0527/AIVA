## 1. 概述：從決策到執行

經過第2冊的 AI 決策流程後，系統已產生經過驗證的參數 JSON。本冊說明如何將這些參數轉換為實際 CLI 命令並執行。

```
第2冊輸出: {"mode": "stealth", "target": "example.com", ...}
     ↓
第3冊: 組裝 → 執行 → 適應
     ↓
最終結果: 掃描報告
```

---

## 2. Step 7-8: 命令組裝

### Step 7: 路徑解析

CommandBuilder 將參數 JSON 轉換為 CLI 命令：

```python
# 從 paths_config.py 取得工具路徑
tool_path = "/usr/local/bin/aiva-scanner"

# 輸入參數
params = {"target": "example.com", "mode": "stealth", "concurrency": 2}
```

### Step 8: 參數拼接

將 JSON 轉換為命令列字串：

| 參數類型 | JSON 值 | CLI 轉換 |
|---------|--------|---------|
| 字串 | `"example.com"` | `--target example.com` |
| 列舉 | `"stealth"` | `--mode stealth` |
| 整數 | `2` | `--concurrency 2` |
| 布林 | `true` | `--safe-check` (flag 存在) |
| 布林 | `false` | (flag 不存在) |

**最終命令**：
```bash
/usr/local/bin/aiva-scanner --target example.com --mode stealth --concurrency 2 --safe-check
```

## 3. Step 9: Flow 執行

### 使用 CLI 執行

```batch
# 執行指定 Flow
執行Flow.bat 11

# 或使用 Python
python -m services.core.aiva_core.core_capabilities.cli.aiva_cli flow11 --target https://example.com
```

### 使用選單執行

```batch
# 啟動選單
啟動能力選單.bat

# 在選單中：
# 1. 選擇模組
# 2. 選擇能力
# 3. 輸入編號執行或 "v 編號" 預覽
```

### Dry Run 模式

在實際執行前預覽：

```batch
# 預覽 Flow
預覽Flow.bat 11

# 或
python -m services.core.aiva_core.core_capabilities.cli.aiva_cli flow11 --target https://example.com --dry-run
```

輸出範例：
```
🔍 Dry Run 模式
📋 Flow 11 執行計畫:
   步驟 1: initial_scan.InitialScan.execute()
   步驟 2: analyzer.VulnAnalyzer.analyze()
   步驟 3: reporter.ReportGenerator.generate()

ℹ️  預覽完成，未實際執行
```

### 掃描階段說明

AIVA 掃描分為兩個階段：

#### Phase 0: 快速偵察 (5-10 分鐘)

```
1. 端口掃描
   - 常見端口 (Top 1000)
   - 服務版本識別
   
2. Web 服務檢測
   - HTTP/HTTPS 識別
   - Web 伺服器類型
   - 框架指紋
   
3. 基礎安全檢查
   - SSL/TLS 配置
   - 常見安全標頭
   - robots.txt 分析
```

**CLI 使用**:
```bash
python aiva_cli.py --attack "快速掃描 http://localhost:3000"
```

#### Phase 1: 深度掃描 (10-30 分鐘)

```
1. 漏洞檢測
   - SQL 注入
   - XSS (跨站腳本)
   - CSRF
   - 文件上傳漏洞
   
2. 配置檢查
   - 敏感檔案暴露
   - 目錄遍歷
   - 弱密碼
   
3. 攻擊面評估
   - 輸入點分析
   - API 端點掃描
   - 參數篡改測試
```

**預期輸出**:
```
🔎 開始 Phase 1 深度掃描...

[1/3] 漏洞檢測
✓ SQL 注入測試: 發現 3 個注入點
✓ XSS 測試: 發現 2 個反射型 XSS
✗ CSRF 測試: 未發現

Phase 1 完成 (用時: 25 分鐘)
發現 11 個漏洞 (高危: 5, 中危: 4, 低危: 2)
```

## 4. Step 10-12: 策略調整與重試

### Step 10: 結果分析

執行完成後，系統分析結果：

| Exit Code | 狀態 | 處置 |
|-----------|------|------|
| 0 | 成功 | 返回結果 |
| 1 | 策略失敗 | 進入 Step 11 |
| 2+ | 程式錯誤 | 報錯終止 |

### Step 11: Strategy Engine 介入

當掃描失敗時（例如被 WAF 攔截）：

```
Stdout: "WAF detected, IP blocked"
Exit Code: 1
     ↓
Strategy Engine 分析:
- 原因: WAF 偵測
- 可能解法: 增加延遲、更換 User-Agent
     ↓
重新查詢 Decision Agent
```

### Step 12: 參數變異

AI 根據失敗原因調整參數：

```json
// 原參數
{"mode": "quick", "concurrency": 10}

// 變異後
{
  "mode": "stealth",
  "concurrency": 2,
  "delay": "2000",        // 新增
  "random-agent": true    // 新增
}
```

**然後回到 Step 7 重新組裝命令**

## 5. 錯誤處理與日誌

### 日誌位置

```
logs/
├── aiva_core/
│   └── app.log          # Core API 日誌
├── cli/
│   └── execution.log    # CLI 執行日誌
└── flow/
    └── flow_XX.log      # 各 Flow 執行記錄
```

### 查看即時日誌

```powershell
# 查看最新日誌
Get-Content -Path logs/aiva_core/app.log -Wait -Tail 50
```

### 常見錯誤處理

| 錯誤類型 | 訊息 | 解決方案 |
|---------|------|---------|
| 模組未找到 | `ModuleNotFoundError` | 檢查 PYTHONPATH |
| 類別未找到 | `找不到類別 XXX` | 重新執行 Pipeline 更新數據 |
| 超時 | `TimeoutError` | 調低 concurrency 或增加 timeout |
| WAF 攔截 | `IP blocked` | 啟用 stealth 模式 |

## 6. 實戰範例

### 範例 1: 基本 Web 掃描

```batch
# Step 1: 執行掃描
python -m services.core.aiva_core.core_capabilities.cli.aiva_cli flow0 ^
  --target https://testphp.vulnweb.com ^
  --intensity 0.5

# Step 2: 查看結果
# 結果會輸出到終端機或指定的輸出路徑
```

### 範例 2: 安全模式掃描

```batch
# 使用低強度避免觸發 WAF
python -m services.core.aiva_core.core_capabilities.cli.aiva_cli flow0 ^
  --target https://example.com ^
  --intensity 0.2 ^
  --param mode=stealth ^
  --param delay=2000
```

### 範例 3: 批次執行多個 Flow

```powershell
# PowerShell 腳本
$flows = 0..5
$target = "https://example.com"

foreach ($id in $flows) {
    Write-Host "執行 Flow $id ..."
    python -m services.core.aiva_core.core_capabilities.cli.aiva_cli "flow$id" `
        --target $target `
        --intensity 0.5
    Start-Sleep -Seconds 2
}
```

### 範例 4: 條件執行

```powershell
# 只有成功才繼續
python -m services.core.aiva_core.core_capabilities.cli.aiva_cli flow0 --target URL
if ($LASTEXITCODE -eq 0) {
    Write-Host "Flow 0 成功，繼續 Flow 1"
    python -m services.core.aiva_core.core_capabilities.cli.aiva_cli flow1 --target URL
}
```

```
Step 7: 路徑解析
```
