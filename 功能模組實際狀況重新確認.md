# AIVA 功能模組實際狀況重新確認

## 📊 功能模組數量確認

### Features 模組：**17 個功能資料夾**

經實際確認 `services/features/` 目錄，確定只有以下 **17 個** `function_` 開頭的功能資料夾：

```
1.  function_authn_go          - 認證/授權漏洞測試（Go 實現）
2.  function_bizlogic          - 業務邏輯漏洞測試
3.  function_crypto            - 加密漏洞分析（Rust 實現）
4.  function_ddos              - DDoS 攻擊測試
5.  function_exploit_framework - 漏洞利用框架
6.  function_forensic          - 取證工具
7.  function_idor              - IDOR 漏洞測試
8.  function_payload_generator - Payload 生成器
9.  function_postex            - 後滲透工具
10. function_reverse_engineering - 逆向工程工具
11. function_social_engineering - 社交工程工具
12. function_sqli              - SQL 注入測試
13. function_ssrf              - SSRF 漏洞測試
14. function_steganography     - 隱寫術工具
15. function_web_scanner       - Web 掃描器
16. function_wordlist_generator - 字典生成器
17. function_xss               - XSS 漏洞測試
```

**之前報告說 18 個的錯誤原因**：誤將非功能資料夾（如 `high_value_manager.py`, `smart_detection_manager.py`）計入。

### 完整指揮流程（以掃描為例）

#### 🎯 階段 1：任務發起

**外部調用**（Integration Module）：
```python
from services.integration.aiva_integration import UnifiedDataManagerV2

# 初始化
manager = UnifiedDataManagerV2()
await manager.initialize_ai()

# 執行掃描任務
result = await manager.execute_scan(
    targets=["https://example.com"],
    scan_type="comprehensive",
    options={
        "max_depth": 3,
        "timeout": 300
    }
)
```

#### 🧠 階段 2：AI 決策（Core Module）

**AICommanderV2 接收任務**：
```python
# services/core/aiva_core/task_planning/ai_commander_v2.py

async def execute_task(
    task_description: str,    # "Scan target for vulnerabilities"
    parameters: dict,         # {"targets": ["https://example.com"], ...}
    domain: Optional[TaskDomain] = None
) -> dict:
    # 1. 識別任務領域
    domain = self._identify_task_domain(task_description, parameters)
    # 返回: TaskDomain.ANALYSIS（因為包含 "scan" 關鍵字）
    
    # 2. 獲取對應協調器
    coordinator = self.coordinators[domain]  # AnalysisCoordinator
    
    # 3. 執行任務
    result = await coordinator.execute_task(coordinator_task)
    
    return result
```

**AnalysisCoordinator 制定計劃**：
```python
# services/core/aiva_core/task_planning/coordinators/analysis_coordinator.py

async def execute_task(task: CoordinatorTask) -> CoordinatorResult:
    # 1. 分析任務需求
    if "comprehensive" in task.parameters.get("scan_type", ""):
        # 需要完整掃描（Phase 0 + Phase 1）
        commands = [
            AICommand(
                command_id=f"{task.task_id}_phase0",
                command_type=CommandType.SCAN_PHASE0,
                target_module="scan",
                payload={
                    "scan_id": task.task_id,
                    "targets": task.parameters["targets"],
                    "max_depth": task.parameters.get("max_depth", 3)
                }
            ),
            AICommand(
                command_id=f"{task.task_id}_phase1",
                command_type=CommandType.SCAN_PHASE1,
                target_module="scan",
                payload={
                    "scan_id": task.task_id,
                    "targets": task.parameters["targets"],
                    "engines": ["nuclei", "katana", "ffuf"]
                }
            )
        ]
    
    # 2. 通過 CommandCenter 執行命令
    results = await self.command_center.execute_batch(commands)
    
    return results
```

#### 📡 階段 3：命令調度（Command Center）

**AICommandCenter 路由命令**：
```python
# services/aiva_common/command_center.py

async def execute(command: AICommand) -> AICommandResult:
    # 1. 檢查處理器
    handler = self._handlers.get(command.target_module)  # "scan"
    # 獲取到: ScanCommandHandler
    
    # 2. 執行命令（帶超時控制）
    result = await asyncio.wait_for(
        handler.handle_command(command),
        timeout=command.timeout
    )
    
    # 3. 返回結果
    return result
```

#### ⚙️ 階段 4：模組執行（Scan Module）

**ScanCommandHandler 處理命令**：
```python
# services/scan/command_handler.py

async def handle_command(command: AICommand) -> AICommandResult:
    # 根據命令類型路由
    if command.command_type == CommandType.SCAN_PHASE0:
        return await self._handle_phase0(command)
    
    elif command.command_type == CommandType.SCAN_PHASE1:
        return await self._handle_phase1(command)

async def _handle_phase0(command: AICommand) -> AICommandResult:
    # 1. 解析命令負載
    phase0_payload = Phase0StartPayload(**command.payload)
    
    # 2. 調用 Rust 引擎執行掃描
    phase0_result = await self.coordinator.execute_phase0(
        scan_id=phase0_payload.scan_id,
        targets=phase0_payload.targets,
        max_depth=phase0_payload.max_depth
    )
    
    # 3. 封裝結果
    return AICommandResult(
        command_id=command.command_id,
        status=CommandStatus.COMPLETED,
        success=True,
        result=phase0_result.model_dump()
    )
```

**MultiEngineCoordinator 協調引擎**：
```python
# services/scan/coordinators/multi_engine_coordinator.py

async def execute_phase0(
    scan_id: str,
    targets: List[str],
    max_depth: int
) -> Phase0Result:
    # 調用 Rust Phase 0 引擎
    result = await self.phase0_engine.scan_targets(
        targets=targets,
        max_depth=max_depth
    )
    
    # 返回標準化結果
    return Phase0Result(
        scan_id=scan_id,
        targets_scanned=len(targets),
        endpoints_discovered=len(result.endpoints),
        tech_stacks_identified=result.tech_stacks,
        sensitive_info_found=result.sensitive_info
    )
```

### 🚧 Features 模組目前狀況（無法接收 AI 命令）

**Features 模組缺少 CommandHandler**：
```python
# ❌ 以下代碼不存在

class FeaturesCommandHandler:

            return await self._handle_xss(command)
        elif command.command_type == CommandType.ATTACK_SQLI:
            return await self._handle_sqli(command)
        # ...
```
