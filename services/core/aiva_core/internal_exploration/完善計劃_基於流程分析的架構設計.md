### Step 3: 新增 `ast_code_analyzer.py`

**核心實現**:
```python
import ast
from pathlib import Path
from typing import List, Dict

class ASTCodeAnalyzer:
    """基於 AST 的代碼分析器"""
    
    def __init__(self):
        self.cache: Dict[str, AnalysisResult] = {}
    
    def analyze_file(self, file_path: Path) -> AnalysisResult:
        """分析單個文件
        
        使用 Python 的 ast 模組：
        1. ast.parse() 解析文件
        2. 遍歷 AST 樹
        3. 提取類、函數、導入
        """
        if str(file_path) in self.cache:
            return self.cache[str(file_path)]
        
        with open(file_path, 'r', encoding='utf-8') as f:
            tree = ast.parse(f.read())
        
        visitor = CodeStructureVisitor()
        visitor.visit(tree)
        
        result = AnalysisResult(
            classes=visitor.classes,
            functions=visitor.functions,
            imports=visitor.imports
        )
        
        self.cache[str(file_path)] = result
        return result


class CodeStructureVisitor(ast.NodeVisitor):
    """AST 訪問器 - 提取代碼結構"""
    
    def visit_ClassDef(self, node):
        """訪問類定義"""
        self.classes.append({
            "name": node.name,
            "bases": [self._get_name(base) for base in node.bases],
            "methods": [m.name for m in node.body if isinstance(m, ast.FunctionDef)],
            "line_start": node.lineno,
            "docstring": ast.get_docstring(node)
        })
        self.generic_visit(node)
    
    def visit_FunctionDef(self, node):
        """訪問函數定義"""
        # 提取參數類型註解
        params = {}
        for arg in node.args.args:
            param_type = self._get_annotation(arg.annotation)
            params[arg.arg] = param_type
        
        # 提取返回類型
        return_type = self._get_annotation(node.returns)
        
        self.functions.append({
            "name": node.name,
            "params": params,
            "return_type": return_type,
            "is_async": isinstance(node, ast.AsyncFunctionDef),
            "line_start": node.lineno
        })
        self.generic_visit(node)
```

```python
import networkx as nx
from pathlib import Path

class KnowledgeGraphBuilder:
    
    def __init__(self):
        self.graph = nx.DiGraph()
    
    def build_from_flow_analysis(self, flow_dir: Path):
        """從流程分析結果構建圖"""
        
        # 1. 讀取所有流程圖
        for md_file in flow_dir.glob("data_flow_chain_*.md"):
            chain = self._parse_flow_chain(md_file)
            
            # 2. 添加節點
            for node in chain.nodes:
                if not self.graph.has_node(node):
                    self.graph.add_node(node, type="script")
            
            # 3. 添加邊（數據流）
            for i in range(len(chain.nodes) - 1):
                from_node = chain.nodes[i]
                to_node = chain.nodes[i+1]
                
                if self.graph.has_edge(from_node, to_node):
                    # 增加流經次數
                    self.graph[from_node][to_node]['weight'] += 1
                else:
                    self.graph.add_edge(from_node, to_node, 
                                      type="data_flow", weight=1)
    
    def query_dependencies(self, node: str) -> Dict[str, List[str]]:
        """查詢依賴"""
        return {
            "direct_dependencies": list(self.graph.successors(node)),
            "reverse_dependencies": list(self.graph.predecessors(node)),
            "all_downstream": list(nx.descendants(self.graph, node)),
            "all_upstream": list(nx.ancestors(self.graph, node))
        }
    
    def find_critical_nodes(self) -> List[Tuple[str, float]]:
        """找出關鍵節點（中心性分析）"""
        centrality = nx.betweenness_centrality(self.graph)
        return sorted(centrality.items(), key=lambda x: -x[1])
```

## 七、總結

### 核心思想：基於流程分析完善架構

1. **已有**: `aiva_flow_analyzer.py` 生成了 268 個流程圖
2. **需要**: 將這些流程圖「結構化」，變成可查詢、可分析的知識
3. **方法**: 
   - AST 分析器提取代碼結構
   - 知識圖譜構建器建立依賴關係
   - 自我診斷工具發現問題
   - 能力註冊中心持久化數據

### 與你的需求對應

你說：「修復其他腳本才有依據」

**依據就是**:
- 知識圖譜告訴你「修改 A 會影響 B, C, D」
- 自我診斷告訴你「A 和 B 之間應該有連接但缺失了」
- 流程分析告訴你「94% 的流程依賴 rl_models，這是關鍵路徑」

### 數據流閉環

```
掃描代碼 → 生成流程圖 → 提取結構 → 構建知識圖譜 
    → 自我診斷 → 發現問題 → 修復代碼 → 重新掃描
    └────────────────────────────────────┘
                數據流閉環
```

這就是 **internal_exploration** 的完整數據流！
