## 2. 檢查標準 {#檢查標準}

根據 `services/aiva_common/README.md` 的規範,功能模組應符合以下標準:

### 必須符合的規範

#### ✅ 1. 命令系統集成
- **實現 CommandHandler 協議**
  ```python
  from services.aiva_common.command_center import CommandHandler
  
  class YourCommandHandler(CommandHandler):
      async def handle_command(
          self, 
          command: AICommand, 
          context: Optional[CommandContext] = None
      ) -> AICommandResult:
          ...
  ```

#### ✅ 2. 使用標準數據合約
- **AICommand**: 統一命令格式
- **AICommandResult**: 標準結果格式
- **CommandType**: 命令類型枚舉
- **CommandStatus**: 執行狀態枚舉

#### ✅ 3. 使用 aiva_common 枚舉和 Schema
- **禁止重複定義**: 不得重新定義 `Severity`、`Confidence`、`TaskStatus` 等
- **正確導入**:
  ```python
  from services.aiva_common.enums import Severity, Confidence
  from services.aiva_common.schemas import FindingPayload
  ```

#### ✅ 4. 統一日誌記錄
- **使用 aiva_common 日誌工具**:
  ```python
  from services.aiva_common.utils import get_logger
  logger = get_logger(__name__)
  ```

#### ✅ 5. 模組專屬枚舉規範
- 允許定義模組特定的枚舉(如 `PayloadType`, `PhishingType`)
- 但必須確保不與 aiva_common 的通用枚舉重複
