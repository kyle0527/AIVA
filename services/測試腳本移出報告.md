## 🔄 移動操作詳情

### 執行的命令：

```powershell
# 創建目錄
New-Item -ItemType Directory -Force -Path "testing/validation_scripts"
New-Item -ItemType Directory -Force -Path "testing/test_servers"

# 移動驗證腳本
Move-Item "services/aiva_common/validate_aiva_common_extensions.py" "testing/validation_scripts/"
Move-Item "services/aiva_common/simple_validation.py" "testing/validation_scripts/"

# 移動測試服務器
Move-Item "tests/services/scan/test_ssrf_server.py" "testing/test_servers/"
```

### 移動原因：

1. **驗證腳本**: 
   - 這些不是 pytest 測試，而是獨立的驗證工具
   - 放在 `testing/validation_scripts/` 更清晰

2. **測試服務器**:
   - 這是測試目標服務器，不是測試腳本
   - 放在 `testing/test_servers/` 更符合其用途
