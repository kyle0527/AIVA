## 📖 名詞解釋

| 術語 | 定義 | 範例 |
|------|------|------|
| **能力 (Capability)** | 唯一的「起點腳本 → 終點腳本」組合 | `monitoring → app` |
| **數據流 (Data Flow)** | 一條完整的路徑，包含所有中間腳本 | `monitoring → core → helper → app` |
| **多路徑能力** | 同一能力有 ≥2 條不同的數據流 | 同樣到 app，但中間經過不同腳本 |
| **單路徑能力** | 能力只有 1 條數據流 | 起點到終點只有一條路徑 |

### 🔍 關係說明

```
能力數量 = 多路徑能力 + 單路徑能力
數據流數量 = Σ(每個能力的路徑數)

例：某模組有 10 個能力
   - 3 個多路徑能力（共 15 條流）
   - 7 個單路徑能力（共 7 條流）
   → 總計 10 能力，22 條數據流
```
