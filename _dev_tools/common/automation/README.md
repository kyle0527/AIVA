# Automation

PowerShell 自動化腳本集。

## 檔案

| 檔案 | 說明 |
|------|------|
| `generate-contracts.ps1` | 生成合約定義 |
| `generate-official-contracts.ps1` | 生成官方合約 |
| `cleanup_deprecated_files.ps1` | 清理廢棄檔案 |
| `system_health_check.ps1` | 系統健康檢查 |
| `analyze_schema_impact.ps1` | Schema 變更影響分析 |

## 使用方式

```powershell
# 執行系統健康檢查
.\system_health_check.ps1

# 生成合約
.\generate-contracts.ps1

# 清理廢棄檔案
.\cleanup_deprecated_files.ps1
```
